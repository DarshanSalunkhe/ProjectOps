## Re-run

`npm run audit:setup` creates a new isolated schema and applies migrations. `npm run audit:browser` runs the public suite. To opt into the synthetic DB workflow, set `AUDIT_RUN_DB_E2E=1` and run the same browser command with local loopback access. The harness reads the audit schema from ignored `.audit/state.json`, verifies its prefix, and uses only `.invalid` test accounts. Do not run outside the test harness against a production database.
